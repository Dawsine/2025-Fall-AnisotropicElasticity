# Tongji 2025 Fall CEA810401各向异性弹性力学（Prof. Nie）

本项目用于存档是Dawsine的Tongji 2025 Fall CEA810401各向异性弹性力学课程作业

非常好板壳力学求解方法进阶，嘎嘎好用

我做了的课程作业包括

- 作业1 综述
- 作业2 位移法
- 作业3 位移函数法
- 作业4+5 状态空间法（二维）混合变量+位移变量
- 作业6 微分求积法
- 作业11 极坐标中的位移函数法
- 作业13+14 状态空间法（三维）混合变量+位移变量
- 同时作业13和14也合并为了期末大作业报告，重点比对了两种方法的计算结果和参数的影

每个作业文件夹下均包含可执行的jupyter notebook文件，可使用Python内核运行，

作业报告以PDF的形式给出，代码执行结果保存为.html文件，可在浏览器中查看。
